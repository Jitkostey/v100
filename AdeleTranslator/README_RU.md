# Adele Translator — обновлённая сборка исходников

## Возможности
- Ctrl+Q: перевод выделенного текста с любого языка на русский во всплывающем окне без замены оригинала.
- Ctrl+R: тихий перевод выделенного русского текста на английский с автоматическим возвратом к исходному окну и заменой выделения; окно с результатом не показывается.
- Глобальные Ctrl+Q / Ctrl+R через Windows RegisterHotKey: сочетания перехватываются системой и не доходят до браузера/активного приложения.
- Компактное окно поверх других окон.
- Перевод через OpenAI Responses API.
- История переводов SQLite.
- Шаблоны Adele с добавлением собственных фраз.
- Буфер обмена и опциональный автоперевод скопированного текста.
- Базовый OCR всего основного экрана через Tesseract.

## Требования
- Windows 10/11
- Python 3.10+
- Интернет и собственный OpenAI API key
- Для OCR: Tesseract OCR for Windows

## Запуск из исходников
Открой PowerShell в папке проекта:

```powershell
py -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
python main.py
```

Добавь API key во вкладке «Настройки» и сохрани настройки.

## Сборка EXE
```powershell
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name AdeleTranslator main.py
```
EXE появится в папке `dist`.

Для OCR установи Tesseract OCR отдельно и добавь путь к `tesseract.exe` в PATH. Затем:
```powershell
pip install mss pillow pytesseract
```

## Важные замечания
- Глобальный hook перехватывает Ctrl+Q и Ctrl+R, пока приложение работает. Поэтому Ctrl+R больше не будет обновлять страницу в браузере, а Ctrl+Q не будет выполнять команду закрытия вкладки в приложениях.
- В Windows защищённый экран, некоторые приложения с повышенными правами и политики безопасности могут ограничивать глобальный hook. Если приложение не перехватывает клавиши, попробуй запуск с тем же уровнем прав, что и целевое приложение.
- Перед нажатием сочетания выдели текст мышью. Приложение временно использует Ctrl+C для чтения выделения и восстанавливает прежний текстовый буфер обмена до завершения перевода.
- Ctrl+R работает в тихом режиме: не открывает окно перевода и не выводит результат в поле предпросмотра. После ответа API программа пытается вернуть исходное окно на передний план и вставить перевод вместо выделения. Если Windows или целевое приложение запрещает активацию/вставку, перевод остаётся в буфере обмена и появляется предупреждение.
- Ctrl+Q показывает перевод во всплывающем окне и не меняет исходный текст.
- Для API-перевода нужен собственный API key. Использование API может тарифицироваться отдельно от подписки ChatGPT.
- Не вводи в программу пароли, платёжные данные и другую чувствительную информацию.
- OCR в этой первой версии распознаёт основной экран целиком; выбор области экрана и языковые пакеты OCR можно добавить в следующем этапе.
- Автоматический перевод буфера обмена выключен по умолчанию, чтобы не отправлять случайно скопированные данные.


## Получение готового EXE через GitHub Actions (без установки Python на твоём ПК)
1. Создай приватный репозиторий GitHub и загрузи туда содержимое папки проекта.
2. Открой вкладку Actions в репозитории.
3. Выбери workflow `Build Adele Translator for Windows`.
4. Нажми `Run workflow`.
5. После завершения открой результат запуска и скачай artifact `AdeleTranslator-Windows`.
6. Внутри будет `AdeleTranslator.exe`.

## Локальная сборка на Windows
Если Python установлен, достаточно запустить `build_windows.bat` двойным щелчком. Готовый файл появится в `dist\AdeleTranslator.exe`.
